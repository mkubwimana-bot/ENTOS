# SME-OS Rwanda

SME-OS is a Rwanda-focused SaaS platform for small and medium enterprises.

## MVP Focus

The first MVP focuses on:

- Tenant/company setup

- Users and roles

- Products and services

- Customers

- Sales

- Payments

- Inventory stock movements

- Customer balances

- Mobile simple transactions

- Limited offline draft capture

- Basic dashboards

## Technology Stack

- Supabase PostgreSQL for database

- Supabase Auth for authentication

- FlutterFlow for frontend

- Cursor for custom code and SQL

- GitHub for version control

## Development Principle

Build the smallest reliable system that real SMEs can use daily.

Avoid overengineering.
